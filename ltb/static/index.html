Beat

Events are held until the next grid slot, so every note lands on the beat. Traffic intensity is sent on each channel as a CC (CC1 = mod wheel by default; −1 = off). Map it to filter cutoff for swells.

Harmony

Scales marked ¼ use quarter tones. Melody and bass voices play them with pitch bend, so set each synth's bend range to match. Chords round to the nearest semitone.

Traffic → Sound

TrafficActivityOnRoleMIDI chProgramOctave RhythmLength (16ths)VelocityMax / barChanceHit note

Each traffic type plays on its own MIDI channel. In your host, put one instrument on each channel. Program sends a Program Change (−1 = none) for multi-timbral or GM synths. Roles: note gives each device its own scale degree; chord/pad play the current chord (pads sustain while that traffic is active); bass plays the chord root; hit plays a fixed note for drums.
